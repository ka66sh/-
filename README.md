# 나라 키우기

가난한 신생국을 100년 동안 운영해 강대국으로 키우는 극사실 국가 경영 시뮬레이션이다.
브라우저에서 돌아가며, 최종 산출물은 더블클릭으로 실행되는 단일 HTML 파일 하나다.

- 게임 기간: 1950년 1월 ~ 2049년 12월 (게임 속 100년)
- 한 판: 1x 기준 시뮬레이션 약 100분 + 결정 시간 약 80분 ≈ 3시간
- 사실감은 그래픽이 아니라 **인과관계**에서 나온다. 오늘의 교육 정책이 20년 뒤 성장률을 바꾼다.

> 설계 기준 문서는 [`PROMPT.md`](./PROMPT.md)다. 작업 규칙 요약은 [`CLAUDE.md`](./CLAUDE.md),
> 진행 상황은 [`PROGRESS.md`](./PROGRESS.md)에 있다.

## 지금 상태

**M0(기반 공사) 완료.** 날짜가 흐르고 배속·일시정지·저장이 동작한다. 경제·인구 모델은 M1부터 들어온다.
계산되지 않은 지표는 화면에서 `—`로 비워 두었다 (근거 없는 수치를 띄우지 않는다).

## 요구 사항

- Node.js LTS (v20 이상, v22에서 개발)
- npm

## 실행

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

## 빌드 (단일 HTML)

```bash
npm run build      # 타입 검사 후 dist/index.html 하나를 만든다
```

`dist/index.html`은 JS·CSS가 모두 인라인된 한 개 파일이다. 파일 탐색기에서 **더블클릭**하면
바로 실행된다. 런타임에 외부 네트워크 요청은 하지 않는다 (완전 오프라인).

> `file://`로 열면 브라우저가 저장소 접근을 막는 경우가 있다. 그때는 게임이 메모리 저장소로
> 자동 전환하고 설정 화면에 이유를 표시한다. 진행 상황은 **설정 → JSON 내보내기**로 보관하라.

## 테스트

```bash
npm test           # 전체
npm run typecheck  # 타입 검사만
```

결정론(같은 시드·같은 명령 → 같은 100년), 저장 왕복, 엔진 순수성(DOM·`Math.random` 금지),
수정자의 지연·감쇠, 체제 324조합을 검사한다.

## 헤드리스 밸런스 시뮬레이터

```bash
npm run sim -- --strategy passive --seed 42 --years 100
npm run sim -- --strategy passive --seed 42 --years 100 --csv out/passive.csv
```

전략 봇이 플레이어 대신 100년을 빠르게 돌리고, 자동 일시정지 횟수와 `simulateMonth` 성능을 출력한다.
밸런스 기준은 `PROMPT.md` §12.2에 있다.

## 조작

| 입력 | 동작 |
|---|---|
| `Space` | 일시정지 / 재생 |
| `1` `2` `3` | 1x · 2x · 4x 배속 |
| 왼쪽 메뉴 | 화면 전환 |

## 콘텐츠 추가하기

정책·이벤트·체제 선택지·시나리오는 모두 `src/data`의 데이터 파일이다. 엔진 코드를 고치지 않고
데이터만 추가하면 된다. 작성 규칙과 틀은 [`CONTENT_GUIDE.md`](./CONTENT_GUIDE.md)에 있다.

## 폴더 구조

```
src/engine/   순수 시뮬레이션 (DOM·브라우저 API 접근 금지, 결정론 보장)
src/data/     콘텐츠 — 정책·이벤트·체제·시나리오
src/game/     시간 루프, 저장/불러오기, 위임
src/ui/       화면, 포맷터
tools/        헤드리스 시뮬레이터
tests/        Vitest
```
